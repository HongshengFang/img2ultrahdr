# `phone-clear` 空间影调复核

2026-09-28。风格名称及默认选项保持 `phone-clear`；此次处理写入 `render.style.algorithm_version = 3`。版本 2 的完整数值基准保存在 [`phone-clear-v2-spatial-baseline.json`](phone-clear-v2-spatial-baseline.json)。原始 DNG／JPEG 与成片仍在 Git 忽略目录中。

## 为什么增加指标

过去只按每张照片的 SDR 中位亮度、HDR 中间调增益和 HDR 第 99.5 百分位判断。这些数值会忽略“同样亮的像素在画面中哪里”：室内人像的脸和背景、洞穴里的岩壁和天空，可以有相同的全局直方图，却有不同观感。

`scripts/audit_phone_clear.py` 现在同时保存：

- SDR／HDR 多个亮度分位数；超过 SDR 白、2 倍白和 3 倍白的面积；阴影、中间调、较亮中间调、高光四档增益。
- 将同拍手机与 repo 成片校正方向和中心裁切后，缩成相同的粗网格，比较**相同位置**的亮度、OKLab 明度与颜色、邻域反差及 HDR 增益。网格比较容忍少量裁切差异，但不代表精确的逐像素配准。
- 手机的 Display P3 SDR／HDR 与 repo 对应图统一转换到 sRGB 后再写入并排 PNG。旧并排图曾直接把 P3 数值写进普通 PNG，会使视觉颜色判断偏差。HDR 列仍是同一映射函数制作的 SDR 预览，不能代替 HDR 屏幕上的原件。

## 保留的处理改动

- 暗景把大面积亮岩壁或灯棚压回更合适的 SDR 亮度，同时依据 RAW 亮度保留少量真正高光。极暗夜景的 HDR 参考亮度单独恢复，避免 SDR 变暗时灯棚的 HDR 也一起变暗。
- 室内低亮度人像使用更深的 SDR 暗部，并减少偏黄橙的暖色。逆光白裙场景只抬起 SDR 阴影，保留白衣和天空的亮部。手动对比度的 Canon 对照图不触发这两项自动微调。
- 试过给所有日景增加整体对比度：虽然少数照片变好，但其他照片的 SDR／HDR 空间误差增大，故未保留。

## 12 组复核结果

下表是每张照片先算误差、再取 12 张的中位数；越低越好。完整的逐张数据与原版本的对比在本地 `outputs/phone_clear_v3_final/audit.json`。

| 指标 | 版本 2 | 版本 3 | 变化 |
| --- | ---: | ---: | ---: |
| 同位置 SDR 亮度误差，EV | 0.367 | 0.324 | −11.9% |
| 同位置 SDR 颜色误差，OKLab | 0.0196 | 0.0176 | −10.4% |
| SDR 分位数亮度误差，EV | 0.319 | 0.205 | −35.7% |
| 四档 HDR 增益误差，EV | 0.357 | 0.261 | −26.9% |
| 同位置 HDR 亮度误差，EV | 0.442 | 0.442 | 持平 |
| 超过 SDR 白的面积误差 | 0.0409 | 0.0409 | 持平 |

暗景 01／05／06 的 SDR 第 90 百分位分别从 `0.604／0.794／0.513` 降至 `0.363／0.396／0.343`，手机对应值为 `0.376／0.363／0.344`。第 06 张夜景的 HDR 第 95 百分位仍约 `0.99`，接近原来的 `0.99`，而手机是 `1.11`。室内人像 07 的同位置 SDR 亮度误差从 `0.383` 降至 `0.244 EV`，颜色误差从 `0.0289` 降至 `0.0192`；逆光白裙 09 的 SDR 亮度误差从 `0.344` 降至 `0.238 EV`。

这些改动缩小了差距，但并非已经匹配手机。日景 02／03／08／10／11／12 的天空、局部白平衡和主体亮度仍可能明显不同。Pixel JPEG 使用的多帧融合、分区白平衡、语义处理和降噪细节无法从这 12 张单帧 DNG 与单张 Canon RAW 反推出同一处理。当前指标也尚未识别人脸、衣服和天空；粗网格无法衡量这些物体的真实语义。

## 复现

```bash
.venv/bin/python scripts/audit_phone_clear.py jpg_hdr_sample_effect \
  --output outputs/phone_clear_v3_final \
  --scene-cache outputs/phone_reanalysis/scenes \
  --baseline docs/phone-clear-v1-baseline.json \
  --reference-audit docs/phone-clear-v2-spatial-baseline.json
```

Canon 的 `0N6A9479.CR2` 和 `0N6A9480.CR2` 仍使用此前确认的手动参数；它们不触发这次新增的自动 SDR 调整。用已保存的线性场景和原参数重出两张图后，SDR 解码像素零差异，HDR 线性文件逐字节一致。原 `natural`／`phone-natural` 的版本与算法未改。
