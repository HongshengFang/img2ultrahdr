# phone-clear V5：自动偏色校正中的肤色保护

本文保留 V5 的历史行为。当前默认已更新为 [V6 RAW 优先白平衡](phone-clear-v6-raw-wb.md)；V6 关闭肤色保护时不会恢复 V4 的整体去暖色。

V4 在人像中暴露了两项叠加问题：自动光源校正降低红色、提高蓝色后，原本较浅的腿部肤色变淡；后续中性暖色去色进一步削弱这些颜色。较红的膝盖受到的影响较小，使同一条腿出现明显的粉色与灰白色差。

V5 保留自动去暖色，并加入肤色保护。风格名仍为 `phone-clear`，`algorithm_version` 从 4 升为 5。

## 处理方式

1. 从 SDR 曝光调整之前的独立预览，使用本机 Apple Vision 取得人物区域；主图与内部参考预览共用这份区域。
2. 对白平衡校正前后都符合肤色特征的像素，结合人物区域生成连续权重。两次颜色判断用于排除校正后已经接近中性的灰衣服、白衣服。
3. 当自动校正过多降低浅肤色的相对色度时，在保留亮度的前提下，有限地回退这次颜色校正。参考色度有上限，因此不会完整保留原始 RAW 中强烈的橙色偏色。
4. 在这些位置减少后续中性暖色去色。背景继续使用完整的偏色校正。

`--skin-protection-strength` 范围为 0..1，自动处理默认 1。设为 0 时恢复 V4 的颜色处理；`natural` 与 `phone-natural` 不变。自动观感关闭、对比度或饱和度被显式覆盖、暗夜场景不启用此层。

人物检测失败时，记录 `color_only_fallback`，并以较弱的颜色权重保护；没有检测到人物时保留原处理。该方法不是精确皮肤分割，暖色衣物等相似颜色仍可能受到部分保护。

## 验证

- 自动测试覆盖浅肤色与深肤色、仍然保留适量白平衡校正、背景与白衣服、偏暖灰衣服、强烈原始橙色偏色、连续边缘和亮度缩放。
- 渲染测试覆盖 SDR 曝光不改变 HDR 的契约、人物区域仅检测一次并供内部参考复用，以及关闭肤色保护后的 V4 兼容性。
- 本地对照样片为 `0N6A9169`（原先观感较好）、`0N6A9416`（白墙前腿部发灰）、`0N6A9479`（室内坐姿）、`0N6A9507`（双人）与 `DSCF8111`（Fujifilm）。从同一显影底稿生成 V4/V5，比较肤色与背景；原始样本和对照仅保存在本地 `outputs/phone-skin-validation/`。
- HDR 文件验证包括增益图检查以及完整 SDR/HDR 解码。缩小 SDR 对照图用于肤色诊断，不能替代 HDR 屏幕上的最终观感复核。

manifest 的 `render.tone_mapping.phone_skin` 记录方法版本、人物检测状态、人物覆盖率、有效肤色权重覆盖率、用户强度与降级原因。
