每张样片需要完成以下检查：

- 单独打开 SDR JPEG，检查曝光、肤色、暗部、渐变和边缘伪色。
- 固定 HDR 显示器亮度，在最新版 Safari、Chrome 和 macOS 照片中查看 Ultra HDR。
- 确认 SDR/HDR 中间调没有明显跳变，高光更亮且没有 halo、色带或局部闪烁。
- 运行 `hdrimg inspect`，记录 gain map、亮度容量、尺寸、ICC/Exif 和两种解码结果。
- 将最终参数和观察结果对应到 `<name>_render.json`，避免按单张照片加入相机专属参数。
