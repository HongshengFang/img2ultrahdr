拖入一张 CR2 或 RAF，等待默认效果生成。调整右侧滑块时显示实时预览；松开后完成精确更新。实时预览会复用最近的局部与颜色分析，最终导出始终使用完整精确处理。

  • HDR / SDR：查看同次处理的两种效果。屏幕没有额外亮度余量时，HDR 画面会按当前显示条件适配。
  • 初始效果：查看当前风格的默认处理。不是未经显影的原始 RAW。
  • 100% 检查：先按原尺寸处理，然后按屏幕物理像素显示。可用触控板滚动或拖动画面平移；双指捏合缩放。
  • 白平衡：自动、相机和自定义可选。首次自定义从 5600 K 和居中色调开始；自动模式不显示推测的色温。
  • 导出：保存 Ultra HDR JPEG；可另存 SDR，并可移除拍摄元数据。最终图像从高精度底稿生成。导出时允许取消。
  • 恢复：重开原片会恢复调整，原片移动后可重新定位。相同内容可以恢复，内容不同的文件不会冒充原片。

调整辅助

  • 语言与外观：工具栏齿轮或 ⌘, 打开设置，选择中文 / English，以及浅色 / 深色 / 跟随系统。
  • 直方图：亮度或 RGB，可显示整张照片的预览、全尺寸或实际导出统计。HDR 白线区分 SDR 白，右侧按 EV 显示高光；橙线是屏幕当前范围。超过 SDR 白是正常 HDR 内容。
  • 边界提示：直方图两端按钮或 J 键。蓝色是接近黑位，红色是接近输出上限，不表示 RAW 传感器过曝。SDR 阈值为编码值 ≤0.5（全部通道）和 ≥254.5（任一通道）；HDR 黑位亮度 ≤0.00001，相对通道上限的 99.9% 为高光提示。
  • 取色：鼠标移入照片显示 RGB 和亮度。HDR RGB 为线性 Rec.2020 百分比，100% 对应参考白；SDR 为 Display P3 的 0–255。nit 是图像相对 203 nit 参考白的换算，不是测量到的屏幕亮度。
  • 白平衡：切换模式先准备底稿；自定义色温、色调拖动时近似预览，松开后重新显影。大幅调整可能在精确更新时出现校正。

0.3 新增与改进

基础影调控件为曝光、高光、阴影、白色色阶、黑色色阶。后两项范围 −100～100，优先调整最亮区域和深暗部，默认为零。双击名称可重置单项，并可撤销。Edit 菜单只保留撤销、重做、剪切、拷贝、粘贴。

连续白平衡选择合并为最后一次请求；已完成的预览和相同显影结果可复用。首次切换到新模式仍需等待精确显影，等待期间保留上一张有效画面。

首次启动与依赖

这是为当前 Mac 构建的本机版。请允许 macOS 的“访问文稿文件夹”请求，应用需要读取现有项目、Python 环境与照片。如果曾拒绝，可到“系统设置 → 隐私与安全性 → 文件与文件夹”启用 Img2UltraHDR 的文稿访问。

应用依赖构建时记录的 Python 环境、RawTherapee、libultrahdr 和 ExifTool。移动项目、删除 Python 环境或卸载工具后，需要恢复它们并重新构建应用；不要求购买 Apple 开发者会员。开发说明见项目中的 docs/macos-app.md。

本地数据

缓存位于 ~/Library/Caches/Img2UltraHDR，默认约 10 GB 上限，优先清理旧会话。调整位于 ~/Library/Application Support/Img2UltraHDR；删除缓存不会删除调整或原片。日志位于 ~/Library/Logs/Img2UltraHDR。

导出过程需要临时磁盘空间；全尺寸图像耗时取决于场景和照片尺寸。所有处理在本机完成。
