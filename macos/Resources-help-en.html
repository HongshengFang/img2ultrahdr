Img2UltraHDR 0.4

Drop one Canon CR2 or Fujifilm RAF. Once the initial look is ready, drag sliders for interactive feedback. Releasing a slider starts precise refinement. Interactive rendering reuses the latest spatial and color analysis; exports always use full-resolution precise processing.

  • Settings: the gear button or ⌘, selects Chinese / English and Light / Dark / System appearance.
  • HDR / SDR: inspect both renditions. SDR displays use the paired SDR image. Display adaptation never changes your export.
  • Initial look: the default processing for the selected style, not undeveloped RAW.
  • White balance: changing modes prepares a new RAW base. Custom starts at 5600 K / neutral tint and remembers your values. Custom sliders preview approximately; release to redevelop precisely.
  • 100%: renders at full resolution. Pinch to zoom, scroll or drag to pan. Starting an edit returns to ordinary preview.
  • Histogram: luminance or RGB, for the whole image rather than the visible crop. Read the sampling label. HDR extends to +2.30 EV above SDR white; the orange marker indicates the current display limit.
  • Output boundary warnings: triangle buttons or J. Blue marks near-black pixels, red marks near the output ceiling. HDR above SDR white is normal. These are not RAW sensor clipping measurements. SDR thresholds are encoded values ≤0.5 in all channels or ≥254.5 in any channel. HDR uses luminance ≤0.00001 and channels ≥99.9% of the 1000-nit limit.
  • Pixel readings: hover over the photo. SDR RGB is Display P3 0–255; HDR is linear Rec.2020 percent and can exceed 100%. Reference nits use 203 nits per unit and are not measured display brightness.
  • Export: Ultra HDR JPEG, optionally with an SDR copy and removal of camera metadata. ICC and HDR data are preserved. Cancel stops the task and does not publish incomplete output.
  • Recovery: reopening the same original restores edits. Use Open to relocate a moved original; its content fingerprint must match.

Local lighting

Choose Edit under Local lighting, then click a point in the photo. The Mac tries to select the foreground object you clicked, including objects other than people. Background clicks, unavailable recognition and an eight-second timeout use a soft range. While selecting, you can choose Use soft range immediately.

New regions start at zero strength. The first Brighten or Darken click sets 50% (±0.25 EV); the slider spans 0–100% (up to ±0.5 EV). Switching direction keeps your strength. Up to eight regions can be selected from the list or their pins, enabled independently and deleted.

Soft ranges begin as a circle with a diameter of 40% of the photo’s shorter side. Drag the center or boundary handles; expand Range for position, 5–200% size, an ellipse, aspect ratio 1:4–4:1 and rotation. Space-drag pans while editing; pinch zoom remains available. Ranges may extend past an edge. Editing returns to ordinary preview; use 100% to check precise detail.

Hold to view before local adjustments keeps the current global settings. Initial look still shows the style’s original defaults. Each drag is one Undo step. Saved smart selections stay fixed when global settings change; move the smart pin or click Reselect range to select a new range. Smart selection does not reliably isolate sky or mountains; a soft range always works.

Selections and edits remain on this Mac. Saved selections live in Application Support, separate from removable cache. If an active saved selection is missing or damaged, export stops with an error. Select that region again, use a soft range, disable it or delete it before exporting.

Basic adjustments

The five basic tone controls are Exposure, Highlights, Shadows, Whites and Blacks. Exposure uses EV. Highlights, Shadows, Whites and Blacks span −100 to +100 over different tonal ranges. Zero keeps the automatic look. If only HDR feels too bright, reduce HDR strength first; if both renditions feel too bright, reduce Exposure. Double-click a label to reset only that setting; the reset is undoable. Edit contains Undo, Redo, Cut, Copy and Paste.

Rapid white-balance selection coalesces into the latest request. Completed previews and identical RAW passes are reused. A first visit to a mode still needs accurate development; the previous valid image remains visible.

Local setup and data

This build copies its engine and Python packages into the app. Keep the recorded local Python standard library, RawTherapee, libultrahdr and ExifTool in place; rebuild after changing source or dependencies. Allow file access if macOS requests it when opening a RAW.

Edits: ~/Library/Application Support/Img2UltraHDR
Cache: ~/Library/Caches/Img2UltraHDR (10 GB target)
Logs: ~/Library/Logs/Img2UltraHDR

Clearing cache does not remove edits or originals. Full-resolution processing needs temporary disk space. All processing stays on this Mac.
