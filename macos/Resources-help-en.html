Img2UltraHDR 0.2

Drop one Canon CR2 or Fujifilm RAF. Once the initial look is ready, drag sliders for interactive feedback. Releasing a slider starts precise refinement. Interactive rendering reuses the latest spatial and color analysis; exports always use full-resolution precise processing.

  • Settings: the gear button or ⌘, selects Chinese / English and Light / Dark / System appearance.
  • HDR / SDR: inspect both renditions. SDR displays use the paired SDR image. Display adaptation never changes your export.
  • Initial look: the default processing for the selected style, not undeveloped RAW.
  • White balance: changing modes prepares a new RAW base. Custom starts at 5600 K / neutral tint and remembers your values. Custom sliders preview approximately; release to redevelop precisely.
  • 100%: renders at full resolution. Pinch to zoom, scroll or drag to pan. Starting an edit returns to ordinary preview.
  • Histogram: luminance or RGB, for the whole image rather than the visible crop. Read the sampling label. HDR extends to +2.30 EV above SDR white; the orange marker indicates the current display limit.
  • Output boundary warnings: triangle buttons or J. Blue marks near-black pixels, red marks near the output ceiling. HDR above SDR white is normal. These are not RAW sensor clipping measurements. SDR thresholds are encoded values ≤0.5 in all channels or ≥254.5 in any channel. HDR uses luminance ≤0.00001 and channels ≥99.9% of the 1000-nit limit.
  • Pixel readings: hover over the photo. SDR RGB is Display P3 0–255; HDR is linear Rec.2020 percent and can exceed 100%. Reference nits use 203 nits per unit and are not measured display brightness.
  • Export: Ultra HDR JPEG, optionally with an SDR copy and removal of camera metadata. ICC and HDR data are preserved. Cancel stops the task and does not publish incomplete output.
  • Recovery: reopening the same original restores edits. Use Open to relocate a moved original; its content fingerprint must match.

Local setup and data

This build uses the recorded local Python environment, RawTherapee, libultrahdr and ExifTool. Keep the project and Python environment in place; rebuild after moving them. Allow access to Documents if macOS requests it.

Edits: ~/Library/Application Support/Img2UltraHDR
Cache: ~/Library/Caches/Img2UltraHDR (10 GB target)
Logs: ~/Library/Logs/Img2UltraHDR

Clearing cache does not remove edits or originals. Full-resolution processing needs temporary disk space. All processing stays on this Mac.
